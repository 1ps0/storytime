Process Rules (46)

  1. SURVEY before ASSEMBLE. Never build a team blind.
  2. ICEBREAKER before BREAKOUT. Shared understanding before depth.
  3. CONVERGE before showing the user. Internal consensus first.
  4. Every technical claim must be grounded — cite code, docs, or external sources.
  5. At least one OPERATOR archetype. Always.
  6. Non-goals and success criteria are required, not optional.
  7. Visual aids use ASCII box-drawing.
  8. Personas are lenses, not characters. No role-play, only expertise.
  9. Team size is appropriate to the project, not fixed. Bias small. Hard ceiling 12.
  10. The user has veto power over everything.
  11. Artifact scan is broad — expect variance across repos.
  12. The user controls depth at every stage.
  13. Rollups replace stale docs.
  14. Archive artifacts must be git-committable and repo-local.
  15. Phases collapse when empty.
  16. Every phase writes its output — a run is a complete snapshot.
  17. Prior runs are prior art — detect and present, never silently overwrite.
  18. Every survey writes a coverage fingerprint.
  19. Effort uses Complexity (how hard) and Scale (how big), never time estimates.
  20. Evaluation hygiene: observe metrics and conclusions separately.
  21. Warm start is detected, not requested.
  22. Preamble narrative is always dynamic.
  23. Personas skip introductions on warm start.
  24. Thread auto-checkpoints at every phase boundary.
  25. Episodes are chapters, not restarts.
  26. Survey delta replaces full survey on warm start.
  27. Post-breakout pause is mandatory (unless auto).
  28. Converge can run standalone.
  29. Grounding is multi-source: code, docs, web, git.
  30. Scale Impact (1-5) alongside Complexity for magnitude.
  31. Evaluation hygiene: don't conflate metrics and conclusions.
  32. Warm start is detected, not requested.
  33. Preamble narrative is always dynamic.
  34. Personas skip introductions on warm start.
  35. Thread auto-checkpoints at every phase boundary.
  36. Episodes are chapters, not restarts.
  37. Survey delta replaces full survey on warm start.
  38. Standalone breakouts are valid.
  39. Always confirm before destructive undo.
  40. Prefer archive over delete.
  41. Redo is undo + immediate retry.
  42. Post-breakout pause is mandatory (unless auto).
  43. Converge can run standalone.
  44. Personas use non-human codenames by default (e.g. anchor, lattice, kestrel). Roles stay the load-bearing address; codenames are ornaments.
  45. One driving persona per leg. Supporters stay silent unless their interjection is both useful AND non-distortive. Round-robin commentary is the failure mode this prevents.
  46. Team size is sized to the work, not the template. Bias small. Tiny problem → tiny team.
