Storytime

A Claude Code plugin that builds technical specifications through structured conversations between domain-expert personas.

$ claude install-plugin ~/workspace/storytime

or per-session: claude --plugin-dir ~/workspace/storytime

How It Works

Describe a problem. Storytime surveys your codebase, assembles a team of domain-expert personas, and runs a structured conversation that produces a plan — grounded in your actual code, with citations, decisions, and visual aids.

Key Concepts

Personas
Domain-expert lenses, not characters. Default core: OWNER, OPERATOR, CRITIC. A SKEPTIC asks "do we need this?" An EDUCATOR unpacks what the team takes for granted. Any persona can @role:explain to teach in context. Every claim cites evidence.
Episodes
Sessions are chapters in an ongoing story. Same topic, continuing narrative. Warm start synthesizes a "previously on..." so you pick up without re-reading the book.
Decisions
Append-only, numbered per topic (RATE-001, RATE-002). They cite the code and personas that drove them. Never deleted, only superseded.
Threads
The bookmark (_thread.md). Tracks episodes, team state, open questions, and last git commit. Park mid-session and resume later with full context.
