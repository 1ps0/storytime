### STORM-001 — Decisions hot, execution cold
  At: 2026-08-02
  Drivers: @user

  Lifecycle_state: sealed

All storm policy is authored in calm with evidence of past storms in
hand — in-storm @user is the failure condition and cannot also be the
designer. The storm plan is a versioned board artifact, freely
editable in calm. In storm, changing it costs one deliberate override
step ("override storm plan"): never locked out — the design law
forbids requesting faith, including from himself — but the default
path is the pre-committed one.

### STORM-002 — Breaker states and trip signals
  At: 2026-08-02
  Drivers: @user
  Status: active
  Lifecycle_state: sealed
  Parent: STORM-001
  Edge_type: refines

States: closed (normal) → open (storm) → half-open (recovery
probation). Hysteresis: trip high, release low, no flapping. Signals
come only from exhaust already emitted, no new tracking (OP-003):
prompt fragmentation and intent-map disorder, correction latency
rising or corrections stopping (worse), loop-opening outrunning
loop-closing, dropped-ask rate, context churn. Manual declare —
"storm" or "calm" spoken by @user — is honored instantly and outranks
every signal. Open: threshold values, window sizes, signal weights
need two or three observed storms to calibrate; manual declare is
primary until then. Sensor substrate: the signal computations ride
FIX-003's event hooks, which are not yet built.

### STORM-003 — The shed order
  At: 2026-08-02
  Drivers: @user
  Status: active
  Lifecycle_state: sealed
  Parent: STORM-002
  Edge_type: refines

Tier 0 never sheds: safety-critical loops, human-waiter loops (never
silently dropped, only renegotiated — STORM-005), capture (STORM-004).
Tier 1 sheds first: exploration, candidates-tray intake, idea-garden
tending, nonessential review. Tier 2 degrades: verification budget
reallocates to top-risk only (VERIF-007); everything else renders
honestly unverified. Open (the worksheet, @user only, calm-time):
enumerate current loops, assign tiers, name the two or three
Tier-0-by-identity items. The one artifact nobody else can write, and
the gate on everything else here — calm is perishable.

  Status: active

In storm, capture gets cheaper, not rarer: voice-only, zero triage,

### STORM-005 — Honest degradation, outward and on the board
  At: 2026-08-02
  Drivers: @user
  Status: active
  Lifecycle_state: sealed
  Parent: STORM-002
  Edge_type: refines
  Callout-> board/BOARD-003 (affects)
  Callout-> board/BOARD-002 (related)

The board in storm: amber and red only, tray closed, lenses to micro,
delta chips suppressed except alarms, zero new asks, decisions queue
unless Tier 0. Unverified work renders gray — the board must show
degraded verification rather than pretend. A board that lies under
load lies exactly when it matters. Outward: a legible degraded-mode
broadcast per affected human-waiter loop — shed window, escalation
path, decisions-queued notice — drafted by the system, sent by @user.
In a no-prior team this teaches the priors deliberately: silence
acquires semantics, slipped dates arrive as renegotiations.

### STORM-007 — Recovery is first-class

  Drivers: @user
  Status: active

Release: saturation below the low threshold for N hours, or declared.
Half-open runs the reconciliation report: what was shed, what
auto-proceeded (receipts attached for audit), which humans are owed
follow-ups (messages pre-drafted), the triage-debt queue, and a
verification catch-up pass ranked by what changed during the storm.
Storm cost is reported once, harvest-style, then out of sight

ambiently.

### VERIF-001 — Verification is budget allocation
  At: 2026-08-02
  Drivers: @user
  Status: active
  Lifecycle_state: sealed
  Callout-> board/BOARD-010 (affects)

Spend @user's minutes by expected loss: blast radius × novelty ×
irreversibility × (1 − probe coverage). The fold computes a risk rank
per change; the review queue orders by it. The low-risk tail is
sampled (VERIF-006), never skimmed.

### VERIF-002 — Review the tests, not the code
  At: 2026-08-02
  Drivers: @user
  Status: active
  Lifecycle_state: sealed
  Parent: VERIF-001
  Edge_type: refines

Highest leverage, zero tooling. The code is the agent's claim; the
tests are the specification of what was actually verified. Red flags
legible from tests alone: tautological asserts, mocks all the way
down, missing negative cases, tests mirroring implementation. Good
tests demote code review to sampling; bad tests end the review — the
tests are the finding.

### VERIF-003 — Mutation testing as dot QA
  At: 2026-08-02
  Drivers: @user
  Status: active
  Lifecycle_state: sealed
  Parent: VERIF-002
  Edge_type: refines

The native failure of agent-written code is self-confirming tests —
the same author wrote the claim and the check. Mutation testing is the
independent auditor neither wrote: mutate, run the suite, count
survivors; every surviving mutant is a mechanical measurement that a
green dot asserts nothing. Surviving mutants auto-file as candidates.
Runs in CI at low cadence — expensive — and surfaces at harvest
boundaries, never ambiently (OP-004). Open: cadence; and first target
is a repo with a real suite (this repo has none — see episode 000).
The dot-grammar amendment this seal motivates is VERIF-P1, registered
below, not sealed here.

### VERIF-006 — Sampling with teeth
  At: 2026-08-02
  Drivers: @user
  Status: active
  Lifecycle_state: sealed
  Parent: VERIF-001
  Edge_type: refines

For the low-risk tail: deep-review a random k%, and a failed sample
escalates its whole class to full review. Skimming everything is the
illusion of review; deep-sampling some is calibrated trust with a
tripwire.

### VERIF-007 — Adversarial pre-pass and storm coupling
  At: 2026-08-02
  Drivers: @user
  Status: active
  Lifecycle_state: sealed
  Parent: VERIF-001
  Edge_type: refines

Before @user's minutes are spent, the agent attacks its own diff —
hunting the stomped clean option, the missing edge, the unraised
objection — and emits structured residue (OP-008 format: solid dots
for measured findings, hollow for judgment). Cheap filter, runs
always. In storm the budget steepens to top-risk only; everything
else goes honestly gray; recovery includes the catch-up pass
(STORM-007).
